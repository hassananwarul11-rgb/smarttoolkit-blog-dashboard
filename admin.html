    Ads & Tracking
    

    Ads Placement — Master Switch
    

    Ads OFF
    

    Master switch sirf ad placements (Header, In-Article, Sidebar) ko control karta hai — OFF ho to koi ad slot nahi dikhega. AdSense header code ka apna Add/Remove switch hai (neeche, Header Code — AdSense). Google Analytics is se alag hai: jab us ka code diya ho, wo hamesha load hoga, chahe Master switch OFF ho.
    

    Header Code — AdSense
    

    AdSense header code lagao (Add) / hatao (Remove)
    



    Switch ON ho aur code diya ho to Publish karne par code site ke <head> me static lag jayega. Switch OFF ho ya code khaali ho to Publish karne par code head se remove ho jayega. Head update hone par Pages deploy mein 1-2 minute lag sakte hain.
    

    Header Code — Google Analytics
    



    Sirf ID likhne par bhi kaam karega — dashboard khud poora GA4 tag bana dega. Analytics Ads switch se alag chalta hai: jab code diya ho, hamesha load hoga.
